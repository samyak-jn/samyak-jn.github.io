# How koji and pungi works together?

## What Koji is

Koji is an open-source build system used to build and manage software packages for RPM-based Linux distributions like Fedora and CentOS. It's a giant factory where software packages are built and tested.

Developers submit source code and build instructions to Koji, which then builds it into an installable package for Linux systems. Koji not only builds but also tests packages through automated tests to ensure quality standards are met.

Once built and tested, packages are added to the Koji build system for use by other developers or inclusion in custom OS images (using tools like Pungi).

Overall, Koji is a powerful tool for managing package-building and ensuring software quality for Linux distributions.

## How Koji and Pungi work together

Koji and Pungi collaborate to create custom operating system images that include packages built using Koji. This allows users to build custom images with specific packages or updates not found in default repositories.

## The process of building custom images using Koji and Pungi

The process involves the following steps:

### Build packages in Koji

Packages are first built in Koji using build instructions and then added to the Koji build system.

### Create a compose configuration

A compose configuration is created using Pungi. This configuration specifies which packages, additional configuration files, or boot files should be included in the custom operating system image.

### Build a package tree

Pungi generates a package tree by downloading and gathering all the software packages required for the custom operating system image. This package tree includes all packages that will be part of the custom image.

### Create a repository

Pungi then takes the package tree and creates a repository of packages. This repository is used to manage and organize all the packages gathered in the previous step, specifically mentioning packages that were built in Koji.

### Compose an image

Pungi composes an image by combining the package tree and the repository. The result is an installable image, such as an ISO or USB image.

### Publish the image

The custom operating system image is then published to a location. From this location, users can download and install the image.

## Overall

The combination of Koji and Pungi provides a powerful set of tools for managing the entire process of building and customizing Linux distributions. By using these tools together, users can create custom operating system images that include specific packages or updates, and distribute them to target machines with ease.
