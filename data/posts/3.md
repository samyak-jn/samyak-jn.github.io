JavaScript has evolved significantly since ES6 (ES2015). Here are the most important features you should know.

## Arrow Functions

Arrow functions provide a concise syntax:

```javascript
const add = (a, b) => a + b;
```

## Destructuring

Extract values from arrays and objects easily:

```javascript
const { name, age } = person;
const [first, second] = array;
```

## Template Literals

Create strings with embedded expressions:

```javascript
const message = `Hello, ${name}!`;
```

## Modules

Organize code with import/export:

```javascript
export function formatDate(date) { ... }
import { formatDate } from './utils.js';
```

## Async/Await

Handle asynchronous operations elegantly:

```javascript
async function fetchData() {
  const response = await fetch(url);
  const data = await response.json();
  return data;
}
```

## Spread Operator

Copy arrays and objects:

```javascript
const newArray = [...oldArray];
const newObj = { ...oldObj };
```

These features make JavaScript more powerful and expressive.
