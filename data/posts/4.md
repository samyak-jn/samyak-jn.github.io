Web accessibility ensures that websites are usable by everyone, including people with disabilities. It's not just the right thing to do—it's often required by law.

## Semantic HTML

Use semantic HTML elements:

```html
<nav>, <main>, <article>, <section>, <header>, <footer>
```

## ARIA Labels

When semantic HTML isn't enough, use ARIA:

```html
<button aria-label="Close menu">×</button>
```

## Keyboard Navigation

Ensure all interactive elements are keyboard accessible:

```css
*:focus-visible {
  outline: 2px solid var(--accent-color);
}
```

## Color Contrast

Maintain sufficient contrast ratios (WCAG AA: 4.5:1 for text):

- Use tools to check contrast
- Don't rely on color alone to convey information

## Alt Text

Always provide alt text for images:

```html
<img src="photo.jpg" alt="Description of the image">
```

## Screen Readers

Test with screen readers like NVDA or VoiceOver to ensure your site is navigable.

Accessibility benefits everyone, not just users with disabilities.
